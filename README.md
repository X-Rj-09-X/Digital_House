# 🚀 Digital House — Formación en Desarrollo de Software

Repositorio personal donde recopilo mi proceso de aprendizaje, prácticas, ejercicios y proyectos desarrollados durante mi formación en **Digital House**.

Este repositorio representa mi recorrido por diferentes áreas del desarrollo de software, desde los fundamentos de programación y desarrollo web hasta bases de datos, backend, metodologías ágiles, cloud computing, testing y preparación profesional.

La idea es mantener en un solo lugar todo lo que voy construyendo y aprendiendo durante el proceso, dejando también un registro de mi evolución como desarrollador.

---

## 🎯 Objetivo del repositorio

Este repositorio tiene como propósito:

* 📚 Organizar los contenidos y proyectos desarrollados durante la formación.

* 🧠 Fortalecer mis fundamentos de programación y desarrollo de software.

* 🚀 Construir proyectos que me permitan llevar la teoría a la práctica.
* 💼 Prepararme progresivamente para el entorno profesional.

# 🔧 Control de versiones

El proyecto utiliza **Git** para el control de versiones y **GitHub** como repositorio remoto.

Algunos de los comandos utilizados durante el proceso son:

```bash
git init
git add .
git commit -m "Descripción del cambio"
git branch
git checkout
git pull
git push
git merge
```
